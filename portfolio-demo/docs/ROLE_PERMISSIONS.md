# ตารางบทบาทและสิทธิ์การเข้าถึง (Role & Permission Matrix)

ระบบออกแบบตามโครงสร้างงานราชการจริง โดยมี 8 บทบาทหลัก:

| Role ID | ชื่อบทบาท (ภาษาไทย) | หน้าที่หลัก | สิทธิ์การเข้าถึงข้อมูลและปุ่มดำเนินการ |
|:---|:---|:---|:---|
| `super_admin` | ผู้ดูแลระบบสูงสุด | ควบคุมดูแลระบบภาพรวมทั้งหมด | เข้าถึงได้ทุกหน้า, อนุมัติสิทธิ์ผู้ใช้, มอบหมายงาน, จัดรถ, เบิกอุปกรณ์, ดู System Logs |
| `admin` | ผู้ดูแลระบบฝ่ายสารบรรณ | รับส่งหนังสือราชการและคัดกรองงาน | ลงรับหนังสือใหม่, แก้ไขรายละเอียดภารกิจ, กำหนดฝ่ายรับผิดชอบ, จัดการสิทธิ์ผู้ใช้ทั่วไป |
| `head_operation` | หัวหน้าฝ่ายปฏิบัติการ | ควบคุมทีมงานภาคสนามและอุปกรณ์ | แต่งตั้งผู้ประสานงานภารกิจ, อนุมัติยืม-คืนอุปกรณ์, ปิดงานภารกิจ |
| `coordinator_operation` | ผู้ประสานงานฝ่ายปฏิบัติการ | จัดเตรียมสถานที่และประสานเจ้าภาพ | รับทราบภารกิจที่ได้รับมอบหมาย, บันทึกผลการประชุมเตรียมการ, ส่งผังจัดตั้งพลับพลา |
| `staff_operation` | เจ้าหน้าที่ฝ่ายปฏิบัติการ | ปฏิบัติการจัดเตรียมสถานที่ | ดูรายละเอียดงานที่มอบหมาย, ยืนยันรับทราบ, ดูตารางเวลาปฏิบัติงาน |
| `head_vehicle` | หัวหน้าฝ่ายยานพาหนะ | ควบคุมการใช้รถราชการและพลขับ | จัดสรรรถตู้/รถบรรทุก, กำหนดคนขับ, จัดการคุณสมบัติพลขับ |
| `staff_vehicle` | เจ้าหน้าที่/พลขับ | ขับรถรับส่งและขนย้ายอุปกรณ์ | ตรวจสอบกำหนดการเดินทาง, ยืนยันการปฏิบัติงานเดินรถ |
| `pending` | ผู้ใช้ใหม่รออนุมัติสิทธิ์ | รอการยืนยันตัวตน | แสดงหน้ายินดีต้อนรับแจ้งสถานะรอแอดมินอนุมัติสิทธิ์ ไม่สามารถเข้าถึงข้อมูลงาน |
